# Проект: Анализ резюме из HeadHunter

## Описание задачи
В рамках учебного проекта по анализу данных выполнена предобработка, разведывательный анализ (EDA) и очистка базы резюме соискателей с сайта `hh.ru` для последующего построения модели прогнозирования заработной платы.

Исходный датасет насчитывает **44 744** строки и **12** признаков. После преобразования и очистки получена таблица размером **44 482** строки и **23** признака.

## Этапы работы
1. **Базовый анализ структуры данных:** изучение типов данных, пропусков и основных статистик.
2. **Преобразование данных:** выделение уровня образования, пола, возраста, опыта работы в месяцах, категории города, готовности к переезду и командировкам, One-Hot Encoding занятости и графика, а также приведение желаемой зарплаты к рублям по историческим курсам валют.
3. **Разведывательный анализ (EDA):** исследование распределений и взаимосвязей признаков с помощью `plotly` (плюс 2 дополнительных исследования по полу/образованию и городам/удалённой работе).
4. **Очистка данных:** удаление полных дубликатов, обработка пропусков, фильтрация аномальных зарплат, резюме с опытом больше возраста и выбросов возраста методом z-отклонений в логарифмическом масштабе.

## Файлы в репозитории
* `Python_для_анализа_данных__Итоговый__проект_Ноутбук-шаблон.ipynb` — основной Jupyter-ноутбук с кодом и выводами.
* `ExchangeRates.csv` — выгрузка курсов валют за 29.12.2017–05.12.2019.
* `charts/` — интерактивные графики `plotly`, сохранённые в формате HTML для просмотра в браузере.
* `.gitignore` — исключение исходного датасета (> 450 МБ) из репозитория.
